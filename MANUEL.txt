AUTEURS & COLLABORATION
-----------------------
Ce projet a ete developpe en collaboration entre :
  - ienien : conception, tests en jeu, validation du mapping
  - OpenCode (IA) : developpement du script, debugging, optimisation

Recherche et developpement effectues ensemble sur plusieurs sessions
de tests, incluant le diagnostic des drivers, la resolution des
conflits manette/clavier, et l'adaptation pour les jeux PC.

Ce pack est le resultat d'une recherche approfondie pour trouver
une solution fonctionnelle sans utiliser reWASD (banni par EAC).


PREREQUIS
---------
- Windows 10/11 (64-bit)
- .NET 9.0 SDK (https://dotnet.microsoft.com/fr-fr/download/dotnet/9.0)
- Python 3.12+ (https://www.python.org/downloads/)
  -> COCHEZ "Add Python to PATH" lors de l'installation
- Navigation Controller Sony (PS Move)
- ScpToolkit installe MANUELLEMENT (https://github.com/nefarius/ScpToolkit/releases)
  -> Cochez "DS3 Controller" et "ScpVBus" lors de l'installation
  -> NE PAS cocher "Xbox 360 Controller"
- HidHide (optionnel, recommande pour Steam)
  (https://github.com/nefarius/HidHide/releases)

INSTALLATION (une seule fois)
------------------------------
1. Copier le dossier NavConPack sur le nouveau PC
2. Ouvrir le dossier 01-INSTALLATION
3. Clic droit sur INSTALL.bat -> "Executer en tant qu'administrateur"
4. Suivre les etapes (Python -> pydirectinput -> verifications)
5. Redemarrer le PC

OPTIONNEL - Pour les jeux Steam (recommande) :
6. Installer HidHide manuellement depuis https://github.com/nefarius/HidHide/releases
7. Redemarrer le PC
8. Relancer INSTALL.bat ou lancer NavCon.exe (configure automatiquement)


NOUVELLE APPLICATION WPF (v3.6.0)
----------------------------------
NavCon.exe est une application Windows (C# WPF) qui remplace les
anciens scripts launch_nav2keys.bat, configurator.bat et nav2keys.py.
Tout est integre dans une seule fenetre :

  Selection preset numerotee
  Demarrer/Arreter le mapping
  Configurer les boutons (5 onglets)
  Test en direct
  Configuration automatique de HidHide

Compilation (si besoin) :
  02-USAGE\compile.bat
  -> Produit 02-USAGE\bin\NavCon.exe

Pour lancer : 02-USAGE\bin\NavCon.exe


UTILISATION QUOTIDIENNE
-----------------------
1. Allumer le Navigation Controller (USB ou Bluetooth)
2. Double-cliquer sur bin\NavCon.exe

La fenetre affiche :
  - La liste des presets disponibles (numerotes)
  - Le statut du mapping [idle] ou [A->space, ...]
  - Le slot du controleur detecte
  - Le statut HidHide

Etapes :
  1. Choisir un preset dans la liste (ou utiliser le config actuel)
  2. Cliquer "Charger" pour appliquer le preset
  3. Cliquer "Demarrer" pour activer le mapping
  4. Lancer votre jeu - la manette agit comme un clavier
  5. Cliquer "Arreter" ou fermer la fenetre pour tout relacher


CONFIGURATION GUI
-----------------
Cliquer sur "Configurer" dans la fenetre principale.

Fonctionnalites (5 onglets) :
  - "Boutons" : Cliquer sur chaque bouton pour choisir sa touche
  - "Trigger L2" : Slider pour le seuil (0-255) + touche L2
  - "Stick Analogique" : Slider deadzone (0-32767) + touches WASD
  - "Presets" : Charger un profil (BF6, COD, ARC, Division) + description
  - "Test en direct" : Tester en temps reel avec vraies touches envoyees
  - Bouton "Sauvegarder" : Ecrit config.json
  - Bouton "Reinitialiser" : Restaure les valeurs par defaut

Les anciens scripts (configurator.bat / configurator.py) fonctionnent
encore mais sont remplaces par NavCon.exe.


MAPPING PAR DEFAUT (Navigation Controller)
------------------------------------------
  Bouton Nav        Touche    Action (exemple)
  ----------------- --------- --------------------------------
  Stick Gauche      WASD      Deplacement
  L3 (clic stick)   Shift     Sprint
  Cross (X)         Espace    Saut
  Circle (O)        C         S'accroupir
  L1                Q         Action rapide
  L2 (trigger)      X         Action alternative
  PS Button         Echap     Pause / Menu
  D-Pad Haut        3         Slot 3
  D-Pad Bas         4         Slot 4
  D-Pad Gauche      1         Slot 1
  D-Pad Droite      F         Interaction

Notes sur les triggers et le stick :
  - Seuil L2 par defaut : 80/255 (reglable dans le configurateur)
  - Deadzone stick par defaut : 7849 (reglable dans le configurateur)


CONFLIT STEAM INPUT
-------------------
Steam Input intercepte tous les controleurs XInput, y compris
le controleur Xbox 360 virtuel cree par ScpVBus. Cela cree
un conflit manette/clavier dans les jeux.

Solution : HidHide (configure automatiquement par NavCon.exe)
  - Masque le controleur virtuel a Steam
  - Autorise python.exe a voir le controleur
  - Configuration automatique via NavCon.exe (admin requis)

Configuration manuelle si besoin :
  1. Win+R -> "joy.cpl" -> Enter
  2. Le controleur Xbox 360 ne doit PAS apparaitre
  3. Si apparait : installer/configurer HidHide

Alternative sans HidHide :
  Steam -> Proprietes du jeu -> Controleur -> "Disable Steam Input"
